# Student Marks Result Checker

This repository contains a simple Python program that checks whether a student has passed or failed based on marks.

## About the Program
The program accepts the student's name and marks as input.
It validates the marks and displays the result.

## Conditions
- Marks range: 0 to 100
- Pass mark: 50 and above
- Below 50: Fail

## Language Used
- Python

## How to Run
1. Execute the Python file
2. Enter student name
3. Enter marks
4. View the result
